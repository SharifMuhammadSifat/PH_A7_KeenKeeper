# Keen Keeper

Name of project: Keen Keeper

Description: Keen Keeper is a small social timeline app that displays friends, their timelines, and activity statistics using local JSON data. It demonstrates a simple Next.js app structure with client-side components and visualizations.

Technologies used:
* Next.js
* React
* CSS
* JavaScript

3 key features of The project
- Friend detail pages: view individual friend information and their timeline.
- Timeline view: chronological posts and interactions for friends.
- Stats page: interactive pichart-based vizualization of timeline summary.
